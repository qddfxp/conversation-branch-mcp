# 分支效果对比评估方法

阶段 3「对比评估」的操作细则。目标：让"新规则到底更好还是更差"有可辩护的结论，而不是凭感觉。做任何 promote/discard 建议前按本文件执行。

## 1. 公平对比四原则

1. **同源输入**：主线 baseline 与分支试跑必须使用完全相同的原始素材（开分支时默认复制 `inputs/`；只有明确不需要时才用 `--no-copy-inputs`）。换素材对比无效。
2. **多样本**：至少 2–3 份覆盖不同特征的素材（如：信息密集的、有争议讨论的、几乎没结论的会议）。单样本偶然命中不构成提升证据。
3. **维度先行**：评估维度在试跑前写进分支 `NOTES.md`，跑完只填表现、不新增/删除维度，避免事后找补。
4. **baseline 对照**：主线 `main/outputs/` 最好保留旧规则产物；没有现成 baseline 时，先按当前主线规则对同一批素材补产出一份，再开分支。

## 2. 评估维度怎么定

维度来自这项长期任务的"硬性要求 + 质量目标"，通常 3–6 个，每个可判定。常见参考：

| 任务类型 | 候选维度 |
|---|---|
| 会议纪要/记录类 | 关键信息完整度、决议与待办准确率（负责人/时间不缺）、结构清晰度、冗余度、客观无臆造 |
| 固定格式文案 | 格式合规率、必填要素覆盖、语言风格一致性、篇幅达标率 |
| 摘要/提炼类 | 要点召回率、无遗漏关键项、概括准确度、可读性 |
| 数据整理/结构化 | 字段完整率、分类准确率、可复核性、错误率 |
| 审稿/分析类 | 问题命中率、依据充分性、可执行性、误报率 |

每个维度用统一刻度，建议三档：`优于主线 / 持平 / 劣于主线`（需要更细可用 1–5 分并注明主线锚点分）。

## 3. 呈现与判断技巧

- **并排成表**：同一份素材的主线产物与分支产物左右并排，逐维度填 `NOTES.md` 的表格，最后给每份素材一行小结。
- **盲评降偏差**：人天然会偏好"新做的那一版"。把两份产物去掉"主线/分支"标签（标 A/B，顺序随机）让用户判，再揭晓；AI 自评时同样先隐去标签。
- **一票否决项先查**：硬性红线（如待办缺负责人、臆造未提及内容、格式缺必填块）一旦触发，无论其他维度多好都判该素材不通过，并在结论中置顶。
- **关注稳定性而非峰值**：分支在难素材上的表现比在简单素材上的漂亮结果更重要。

## 4. 结论三分与建议口径

- **提升**：多数样本多数维度占优、无一票否决、优势与本次改动目的一致 → 建议 `promote`，并在 `--note` 里写明证据（哪些素材、哪些维度胜出）。
- **持平**：互有胜负或差异不明显 → **默认保留主线，不为变而变**；可在分支继续迭代后再评，或 discard。
- **变差**：触发一票否决，或关键维度稳定劣化 → 建议 `discard`，并在 NOTES 记录失败原因（这是有价值的负证据，归档分支会保留它）。

AI 只输出带证据的建议，最终 promote/discard 由用户明确决定。

## 5. 多分支横向对比

多个候选分支（如三种风格）时，用脚本承载机械工作，AI 专注判断：

1. 先跑 `compare <root>` 生成 COMPARE.md，确认各分支基于同一主线版本（"落后"标记的分支先处理基准问题）、使用同一批素材；
2. 以 COMPARE.md 的改动量总表为索引，逐个读各分支 outputs/ 产物，做一张评估总表：行=维度，列=主线与各分支，单元格填排名或档位，阶段判断随时用 `note` 写回分支；
3. 接近的两个候选用 `diff <root> <A> --against <B>` 细看规则层面的真实分歧，避免被产物的偶然差异误导；
4. 只提升一个最终胜出分支（promote），其余用 `discard <root> --keep <赢家>` 一次清理；
5. 提升后仍保留的分支基于旧主线，COMPARE/status 会标"落后"：提示用户对照基准已变化，必要时从新主线重新开分支。

## 6. NOTES.md 填写示例

```
## 评估维度（试跑前定）
| 维度 | 主线 | exp-a | 胜出 |
|---|---|---|---|
| 待办要素完整 | 完整 | 完整 | 平 |
| 决策背景可追溯 | 缺失 | 补齐 | exp-a |
| 篇幅冗余度 | 简洁 | 略长 | 主线 |
| 无臆造（红线） | 通过 | 通过 | 平 |

## 样本结论
- 素材1（信息密集）：exp-a 胜在背景完整，无红线问题
- 素材2（争议讨论）：主线漏掉争议来由，exp-a 记录完整
- 素材3（短会）：两者持平

## 结论：提升（3 份样本中 2 份关键维度胜出，无一票否决）→ 请用户确认 promote
```
